# 星象与机械历法 · 典藏扑克牌组

Celestial Horology Playing Cards 是一个 Vite、React 和 TypeScript 构建的静态扑克牌图鉴，共收录 52 张花色牌与太阳、月亮两张王牌。

## 使用

- **全副图鉴**支持花色筛选。打开任意藏牌后，轻触或横滑翻面，拖动或双指移动可倾斜牌面、改变箔光位置。键盘左右键切换藏品，Esc 退出。
- **牌阵抽牌**提供单张指引和过去、现在、未来三张时序。洗牌会重新排列整副牌，每组牌阵从同一副牌中无放回抽取。
- **工艺透视**可选择任意样张，独立开关线稿、油墨和烫金印版。

## 印版设计

54 张牌共用 210 × 306 的画幅、角标、边线和星象编号。四种花色分别取意于子午仪、摆钟、行星齿轮和测角规。宫廷牌以 J、Q、K 的头饰与执物区分身份，以花色对应的仪器区分职掌。人像绕牌心旋转 180° 配对，日月王牌沿用这条对称轴。朱砂用于红桃与方片，铜金用于刻度、齿轮、轮廓和边饰。

矢量原稿位于 `src/Art.tsx`。开发和构建脚本会预先导出牌面、牌背和独立的金箔蒙版，供图鉴按需载入。工艺视图直接渲染同一份 SVG 原稿。

## 本地运行

使用 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

生产静态文件位于 `dist/`。所有插画在本地生成，页面运行无需服务端、API 密钥或外部图片服务。

## 发布

推送至 `main` 或在该分支手动运行 Deploy celestial archive，会执行类型检查与构建。工作流将验证过的静态文件同步至 `gh-pages`，再请求 GitHub Pages 从该分支根目录发布。Vite 的相对资源路径支持仓库子路径。

# 圣彼得堡的七月 · 《罪与罚》意识流档案

独立静态应用，使用 Vite、React 与 TypeScript，所有图像、文字和声音合成逻辑随站点提供。首页河岸为创作性版画插图，漫游地图为文学路径示意。人物立场和意象解析为原创阅读批注，体温、焦虑值与清醒度是表现视角的拟值。

## 本地运行

在本目录使用 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

执行 `npm run build` 进行严格类型检查与生产构建，执行 `npm run preview` 检视生成的 `dist/`。

## 阅读

- 意识天平提供六个命题与两种视角。黄铜器械以阻尼弹簧响应倾斜，图旁批注与三项读数同步变化。
- 漫游支持点选地图和地点栏、在地点栏水平滑动，以及翻看物证背面的意象批注。
- 人物志保留所选主题，切换人物即可并读四种立场。
- 右上角可开启细雨、钟声与随天平变化的心跳。页面尊重系统的减弱动态效果设置。

## GitHub Pages

源码在仓库的 `petersburg-dossier/`。仓库根目录的 `.github/workflows/deploy.yml` 构建两个站点，把本应用的构建结果放到最终站点的 `petersburg-dossier/`。工作流通过现有 `gh-pages` 分支发布。原站入口为 `/111/`，本应用入口为 `/111/petersburg-dossier/`。
